# Header Image Setup Instructions

## To use your custom header image:

1. **Save the image you provided** as `header-image.png` in the same folder as your website files
2. Make sure the image is saved with exactly this filename: `header-image.png`
3. The image will automatically appear as the background of your header section

## Current Setup:
- The website is now configured to use `header-image.png` as the header background
- The "Snowandice" title and "Enjoy with ice!" tagline will appear centered over the image
- The layout has been optimized to work perfectly with your beautiful ice cubes image

## File Requirements:
- **Format**: PNG (recommended) or JPG
- **Filename**: Must be exactly `header-image.png`
- **Location**: Same folder as index.html
- **Recommended size**: 1400x400 pixels or larger for best quality
