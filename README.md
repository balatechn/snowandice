# SnowandIce - Premium Ice Machine Solutions

A modern, responsive website for SnowandIce, featuring premium ice machine solutions with an elegant ice-blue gradient design theme.

## 🎨 Design Features

- **Modern Ice-Blue Gradient Theme**: Multi-layered gradients throughout all UI elements
- **Glass-morphism Navigation**: Floating navigation with blur effects and smooth transitions
- **Compact Navigation**: 14px font size, reduced padding (6px 10px), and optimized spacing
- **Professional Business Styling**: Machine-specific gradient backgrounds for commercial context
- **Responsive Design**: Optimized for all devices with mobile-first approach
- **Enhanced Shadows**: Depth and dimension with sophisticated shadow effects
- **Smooth Animations**: Hover effects and transitions on all interactive elements

## 🚀 Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/balatechn/snowandice.git
cd snowandice
```

2. Start a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Using PHP
php -S localhost:8000
```

3. Open your browser and navigate to `http://localhost:8000`

### GitHub Pages Deployment

This website is automatically deployed using GitHub Pages. Any changes pushed to the main branch will be reflected on the live site.
